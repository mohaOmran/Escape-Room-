# Escape-Room-

🔐 An interactive Escape Room game built with vanilla JavaScript over a 10-day challenge — explore the room, find clues, solve puzzles, and escape.

## Project Structure

```text
Escape-Room-/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── app.js
└── README.md
```

## Run the Project

Open `index.html` directly in a browser, or serve the repository locally:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## How to Play

1. Search the painting, desk, and clock.
2. Solve each puzzle to collect a clue.
3. Inspect the door and enter the combined clue code.
4. Escape before the 10-minute timer reaches zero.
